# PRD Mentor MAGIS

## Tujuan
Mendefinisikan kebutuhan sistem untuk role Mentor pada proses pembinaan mahasiswa magang.

## Ruang Lingkup
1. Monitoring mahasiswa bimbingan.
2. Validasi logbook harian.
3. Penilaian akhir mahasiswa.

## Kebutuhan Fungsional
1. Mentor dapat melihat daftar mahasiswa bimbingan dan progresnya.
2. Mentor dapat menyetujui atau menolak logbook dengan catatan revisi.
3. Mentor dapat mengisi skor penilaian aspek evaluasi.
4. Sistem menghitung nilai akhir otomatis berdasarkan skor mentor.

## Acceptance Criteria
1. Logbook yang divalidasi langsung memperbarui status.
2. Penolakan logbook wajib menyertakan komentar.
3. Nilai akhir tersimpan setelah submit penilaian.
