# PRD - Mahasiswa - Logbook Harian

## Tujuan
Mendokumentasikan aktivitas kerja harian mahasiswa selama magang.

## Kebutuhan Fungsional
1. Input narasi kegiatan harian.
2. Upload bukti kegiatan.
3. Submit dan revisi logbook.

## Acceptance Criteria
1. Logbook tidak bisa submit jika deskripsi kosong.
2. Status validasi tampil jelas (pending/disetujui/ditolak).
