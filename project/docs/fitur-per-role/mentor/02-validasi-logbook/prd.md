# PRD - Mentor - Validasi Logbook

## Tujuan
Menjamin kualitas laporan harian mahasiswa.

## Kebutuhan Fungsional
1. List logbook pending.
2. Aksi setujui/tolak.
3. Komentar revisi saat penolakan.

## Acceptance Criteria
1. Setiap logbook punya status validasi.
2. Penolakan wajib menyertakan komentar.
