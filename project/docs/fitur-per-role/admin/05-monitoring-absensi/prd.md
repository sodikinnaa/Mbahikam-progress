# PRD - Admin - Monitoring Absensi

## Tujuan Fitur
Menyediakan pemantauan absensi mahasiswa agar admin dapat melihat kedisiplinan kehadiran.

## Ruang Lingkup
Hanya mencakup tampilan rekap absensi, filter data, dan akses detail presensi.

## Pengguna
- Admin Kominfo

## Kebutuhan Fungsional
1. Admin dapat melihat dashboard rekap absensi mahasiswa.
2. Admin dapat memfilter data berdasarkan periode dan tanggal.
3. Sistem menampilkan data check-in dan check-out mahasiswa.
4. Admin dapat membuka detail riwayat presensi per mahasiswa.
5. Sistem menampilkan indikator anomali absensi.

## Kebutuhan Non-Fungsional
1. Dashboard absensi harus responsif untuk menampilkan data rekap.
2. Filter harus memperbarui data tanpa kesalahan perhitungan.

## Acceptance Criteria
1. Rekap absensi tampil sesuai periode dan tanggal yang dipilih.
2. Detail presensi mahasiswa dapat dibuka dari dashboard.
3. Anomali absensi dapat diidentifikasi dari indikator yang ditampilkan.
4. Data check-in dan check-out yang tampil konsisten dengan data tersimpan.
