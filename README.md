# MAGIS - Keterangan Project

MAGIS (Magang Informasi dan Sistem) adalah sistem informasi manajemen magang berbasis web untuk mendukung proses magang di Dinas Kominfo secara terintegrasi.

## Latar Belakang

Pengelolaan magang yang masih manual menyebabkan proses pendaftaran, absensi, logbook, penilaian, dan pelaporan menjadi lambat serta sulit dipantau. Project ini disusun untuk menyiapkan dokumen kebutuhan dan alur sistem agar pengembangan aplikasi berjalan terarah.

## Tujuan Project

1. Menyusun alur proses magang yang jelas untuk setiap role.
2. Menyusun PRD per fitur agar implementasi lebih terstruktur.
3. Menstandarkan status dan proses lintas role (Admin, Mentor, Mahasiswa).
4. Menyiapkan bahan dokumentasi untuk tahap review dan pengembangan.

## Ruang Lingkup Dokumen

Dokumen yang disiapkan pada workspace ini meliputi:

1. Dokumen inti level sistem:
- Flowchart global.
- Flowchart role-based.
- PRD Admin.
- PRD Mentor.
- PRD Mahasiswa.
- PRD Cross-role.
2. Dokumen detail per fitur untuk tiap role (Admin, Mentor, Mahasiswa):
- 1 flowchart per fitur.
- 1 PRD per fitur.

## Role Utama

1. Admin Kominfo.
2. Mentor atau Pembina.
3. Mahasiswa Magang.

## Jumlah Modul per Role

1. Admin: 7 modul.
2. Mentor: 3 modul.
3. Mahasiswa: 5 modul.
4. Total modul role-based: 15 modul.
