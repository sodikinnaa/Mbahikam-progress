# PRD - Mahasiswa - Laporan Akhir dan Nilai

## Tujuan
Memastikan penutupan proses magang dengan laporan akhir dan hasil evaluasi.

## Kebutuhan Fungsional
1. Upload laporan akhir.
2. Lihat status kelulusan.
3. Lihat nilai akhir.

## Acceptance Criteria
1. Laporan akhir tersimpan dengan sukses.
2. Nilai akhir tampil setelah finalisasi mentor.
