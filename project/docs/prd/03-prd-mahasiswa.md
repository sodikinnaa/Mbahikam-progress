# PRD Mahasiswa MAGIS

## Tujuan
Mendefinisikan kebutuhan sistem untuk role Mahasiswa selama siklus kegiatan magang.

## Ruang Lingkup
1. Registrasi dan profil.
2. Pendaftaran dan upload berkas.
3. Presensi harian.
4. Logbook harian.
5. Laporan akhir dan akses nilai.

## Kebutuhan Fungsional
1. Mahasiswa dapat memiliki akun melalui registrasi mandiri atau akun dari admin.
2. Mahasiswa dapat mengajukan pendaftaran dengan berkas syarat.
3. Mahasiswa dapat melakukan check-in dan check-out harian.
4. Mahasiswa dapat mengirim logbook serta revisi jika diminta mentor.
5. Mahasiswa dapat upload laporan akhir dan melihat nilai akhir.

## Acceptance Criteria
1. Status pendaftaran dan logbook dapat dipantau mahasiswa.
2. Presensi tersimpan dengan timestamp.
3. Nilai akhir dapat dilihat setelah penilaian mentor selesai.
