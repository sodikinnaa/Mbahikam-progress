# Flowchart Per Role MAGIS

## 1. Alur Mahasiswa

1. Registrasi akun
2. Login
3. Isi profil dan data magang
4. Upload berkas persyaratan
5. Submit pendaftaran
6. Cek status pendaftaran
7. Jika diterima:
   - Check-in harian
   - Input logbook
   - Upload bukti kegiatan
   - Cek hasil validasi mentor
   - Revisi jika ditolak
   - Check-out harian
8. Upload laporan akhir
9. Lihat nilai akhir
10. Logout

## 2. Alur Admin

1. Login admin
2. Kelola periode magang dan kuota
3. Lihat pendaftaran masuk
4. Validasi pendaftaran (terima/tolak)
5. Input mahasiswa manual (jika diperlukan)
6. Assign mentor ke mahasiswa aktif
7. Monitoring absensi
8. Monitoring logbook
9. Kelola data master (mahasiswa, mentor)
10. Generate laporan dan export
11. Logout

## 3. Alur Mentor

1. Login mentor
2. Lihat daftar mahasiswa bimbingan
3. Review logbook harian
4. Validasi logbook:
   - Setujui
   - Tolak + catatan revisi
5. Input penilaian akhir
6. Finalisasi penilaian
7. Logout
