# PRD Role: Mentor/Pembina

## Ringkasan
Mentor berfokus pada pembinaan kualitas aktivitas magang, validasi logbook, dan penilaian kinerja akhir mahasiswa.

## Tujuan Produk (Mentor)

1. Memudahkan review logbook harian.
2. Menjaga kualitas laporan kegiatan mahasiswa.
3. Menstandarkan penilaian akhir berdasarkan aspek kompetensi.

## Fitur Utama

1. Login/logout mentor
2. Lihat daftar mahasiswa bimbingan
3. Review logbook harian
4. Validasi logbook (setuju/tolak + komentar)
5. Input nilai akhir
6. Finalisasi penilaian

## Daftar Kebutuhan Fungsional

1. Mentor dapat melihat antrean logbook pending.
2. Mentor dapat menyetujui logbook jika sesuai.
3. Mentor dapat menolak logbook dengan alasan wajib isi.
4. Mentor dapat memberi nilai berdasarkan aspek:
   - Analisis
   - Komunikasi
   - Kerja sama tim
   - Disiplin
5. Mentor dapat submit penilaian final per mahasiswa.

## Kriteria Penerimaan (Acceptance Criteria)

1. Setiap logbook memiliki status validasi yang jelas.
2. Logbook yang ditolak wajib memiliki catatan revisi.
3. Nilai akhir hanya bisa final jika semua aspek terisi.
4. Mahasiswa dapat melihat hasil final setelah mentor submit.

## Data yang Dibutuhkan

1. Data mentor
2. Relasi mentor-mahasiswa
3. Data logbook mahasiswa
4. Data penilaian
5. Riwayat validasi

## KPI Mentor

1. Rata-rata waktu validasi logbook
2. Persentase logbook tervalidasi tepat waktu
3. Kelengkapan penilaian akhir mahasiswa bimbingan
