# PRD Admin MAGIS

## Tujuan
Mendefinisikan kebutuhan sistem untuk role Admin pada proses manajemen magang.

## Ruang Lingkup
1. Kelola periode magang.
2. Validasi pendaftaran mahasiswa.
3. Input mahasiswa manual.
4. Assign mentor.
5. Monitoring absensi dan logbook.
6. Laporan dan export.

## Kebutuhan Fungsional
1. Admin dapat mengelola periode magang beserta kuota.
2. Admin dapat memvalidasi pendaftaran dan berkas mahasiswa.
3. Admin dapat membuat akun mahasiswa secara manual.
4. Admin dapat menetapkan mentor untuk mahasiswa aktif.
5. Admin dapat melihat dashboard monitoring absensi dan logbook.
6. Admin dapat mengekspor laporan ke PDF atau Excel.

## Acceptance Criteria
1. Semua aksi admin tercatat pada log sistem.
2. Status pendaftaran, assignment mentor, dan monitoring tampil konsisten.
3. Laporan dapat digenerate sesuai periode.
