# PRD - Mahasiswa - Presensi Harian

## Tujuan
Mencatat kehadiran harian mahasiswa secara digital.

## Kebutuhan Fungsional
1. Check-in harian.
2. Check-out harian.
3. Simpan selfie dan timestamp.

## Acceptance Criteria
1. Data check-in/check-out tersimpan.
2. Mahasiswa dapat melihat riwayat presensi.
