# Struktur Fitur Per Role

Format yang digunakan:

role/
- fitur/
  - flowchart.md
  - prd.md

Role yang tersedia:
1. mahasiswa
2. admin
3. mentor

Aturan penulisan:
1. Satu folder hanya untuk satu fitur.
2. Flowchart harus memakai format Mermaid.
3. PRD hanya membahas fitur pada folder tersebut, tidak melebar ke fitur lain.
