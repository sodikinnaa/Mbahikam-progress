# PRD - Mentor - Penilaian Akhir

## Tujuan
Memberikan evaluasi akhir kinerja mahasiswa secara terstandar.

## Kebutuhan Fungsional
1. Form nilai per aspek.
2. Kalkulasi nilai akhir otomatis.
3. Submit final nilai.

## Acceptance Criteria
1. Semua aspek nilai wajib terisi.
2. Nilai akhir tersimpan setelah submit.
