# PRD - Mentor - Monitoring Mahasiswa

## Tujuan
Memberi visibilitas progres mahasiswa kepada mentor.

## Kebutuhan Fungsional
1. Daftar mahasiswa bimbingan.
2. Detail aktivitas mahasiswa.
3. Ringkasan progres per mahasiswa.

## Acceptance Criteria
1. Mentor dapat melihat semua mahasiswa bimbingan.
2. Progres aktivitas tampil per mahasiswa.
