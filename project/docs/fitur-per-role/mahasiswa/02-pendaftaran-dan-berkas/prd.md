# PRD - Mahasiswa - Pendaftaran dan Berkas

## Tujuan
Memfasilitasi pengajuan pendaftaran magang beserta dokumen pendukung.

## Kebutuhan Fungsional
1. Upload multi-berkas.
2. Submit pendaftaran.
3. Lihat status pendaftaran.

## Acceptance Criteria
1. Semua berkas wajib dapat diunggah.
2. Setelah submit, status pendaftaran tampil Pending.
